# Sistema de Gestión Comercial - Centermuebles

Aplicación web desarrollada en C# y SQL Server para la administración de ventas, clientes y productos.

## Funcionalidades

- Gestión de clientes
- Gestión de productos
- Registro de ventas
- Control de stock automático
- Validaciones y reglas de negocio

## Tecnologías utilizadas

- C#
- .NET
- SQL Server
- Programación Orientada a Objetos
